# hajime-dictionary

[Hajime IME](https://github.com/KikuchiTomo/Hajime) のかな漢字変換の辞書です．[azooKey](https://github.com/azooKey/AzooKeyKanaKanjiConverter) の辞書に，[Mozc](https://github.com/google/mozc) の辞書(dictionary_oss)にしかない語と，[Wikidata](https://www.wikidata.org/) から作った外来語の英字の綴り(「レッドハット」→ Red Hat，「にゅーらる」→ neural)を足し，さらに [Mozc UT 辞書](https://github.com/utuhiro78)(SudachiDict・NEologd・人名・地名・Wikipedia の見出し・EDICT2)と，NEologd・SudachiDict の元のデータの語を足しています．v0.5.0 から，分野ごとに使うかを選べる専門用語の辞書(`Dictionary/terms.tsv`．JMdict と Wikidata の語)も含めています．v0.4.0 から CC BY-SA 4.0 の語を含むので，辞書は CC BY-SA 4.0 の条件で配布します(「ライセンス」)．azooKey の辞書と同じ形(LOUDS)なので，azooKey のエンジンを使う IME から読めます．

## 入手

[Releases](https://github.com/KikuchiTomo/hajime-dictionary/releases) から `hajime-dictionary-<版>.tar.gz` を取得してください．SHA-256 は同じ場所の `.sha256` にあります．展開した `Dictionary/` を，azooKey のエンジンに辞書のディレクトリとして渡します．

```swift
let converter = KanaKanjiConverter(dicdataStore: DicdataStore(dictionaryURL: dictionaryDirectory))
```

`Dictionary/SHA256SUMS` に辞書のファイルごとの SHA-256 があります．使う側で一覧の SHA-256 を持っておき，一覧と各ファイルを確かめてから読むと，差し替えられた辞書を読まずに済みます．

辞書の形は AzooKeyKanaKanjiConverter の版に合わせています．作るときに使った版は `builder/Package.swift` の revision です．

## 作り方

```sh
./build.sh 0.5.3
```

Swift 6.1 以降と Python 3 が要ります．Python のスクリプトは標準ライブラリだけで動きます．

1. `tools/fetch_sources.sh` が，`sources/sources.txt` に書いた元のデータを取得し，SHA-256(azooKey の辞書は git のコミット)を確かめます
2. `tools/dump_azookey.py` が，azooKey の辞書の語をすべて TSV に書き出します
3. `tools/merge_mozc.py` が，Mozc にしかない語を足します
   - 品詞: azooKey の品詞の番号は IPAdic の left-id と同じです．Mozc の id.def の品詞の文字列を，IPAdic の番号に引き直します．活用の行が決まっていない品詞(「五段動詞」など)の語は，正しく対応しないので足しません
   - コスト: 両方の辞書にある同じ品詞の語から，Mozc のコストの区間ごとに azooKey の値の中央値を求め，その間を線形に補って換算します
   - 読みが 4 文字より短い語は足しません．短い読みでは，まれな語が既存の語を押しのけて変換を悪くしたためです(「じたい」が「次隊」になるなど)
   - 読みをわざと誤らせた表記ゆれの補正の行(SPELLING_CORRECTION)は足しません
   - 壊れた書き方の語(下の「壊れた書き方」)は足しません．azooKey の辞書の語からも，文節の切れ端になる語を除きます
   - 助数詞の音の変わる読み(匹 の ピキ・ビキ など)を足します(下の「助数詞の音の変わる読み」)
4. `tools/add_loanwords.py` が，外来語の英字の綴りを足します(下の「外来語の英字の綴り」)
5. `tools/add_ut.py` が，Mozc UT 辞書の語を足します(下の「Mozc UT 辞書の語」)
6. `tools/add_neologd.py` と `tools/add_sudachi.py` が，NEologd と SudachiDict の元のデータの語を足します(下の「NEologd と SudachiDict の元のデータの語」)
7. `tools/demote_sokuon_variants.py` が，促音を落とした読みの揺れの値を下げます(下の「促音を落とした読みの揺れ」)
8. `tools/build_terms.py` が，専門用語の辞書(`terms.tsv`)を作ります(下の「専門用語の辞書」)
9. `tools/assemble.sh` が，fork の `DictionaryBuilder` で LOUDS を作ります．接続のコスト・予測・意味の接続は azooKey の辞書のものをそのまま使います

語を足す道具のテストは `python3 -m unittest discover -s tests` で動きます(除く語の決まり・壊れた書き方・揺れの読み・NEologd と SudachiDict の語の足し方・専門用語の辞書の作り方)．

## 外来語の英字の綴り

`sources/wikidata-loanwords.tsv` は，`tools/fetch_wikidata.py` が Wikidata(CC0)から作った「カタカナの読みと英字の綴り」の一覧です．辞書を作るときはこのファイルだけを使い，Wikidata には問い合わせません．作り直すときは次を動かし，差分を確かめてからコミットします．

```sh
python3 -I tools/fetch_wikidata.py sources/wikidata-loanwords.tsv --raw work/wikidata-raw.json
```

- 一覧に残すのは，日本語のラベルか別名がカタカナだけの項目のうち，英語のラベルとカタカナの子音の並びが似ているものです(同じ項目でも名前の違う別の物を除くため)．曖昧さ回避・生物の分類群・論文などの項目は除きます．固有名詞は 15 以上，人は 50 以上の言語版がある項目だけを残します
- 辞書に足すのは，同じ読みのカタカナ語が辞書にあるか，読みが辞書に無い語だけです．かなや漢字の語だけがある読み(「サンサイ」→ 山菜)には足しません
- 打ち方の揺れの読み(ヴ → ブ，トゥ → ツ，末尾の長音を除いたもの)も足します．「ウブンツ」でも Ubuntu が出ます
- 値は，同じ綴りが別の読みで辞書にあればその値に，同じ読みのカタカナ語があればその語の少し下に合わせます．カタカナ語が先に出て，英字はその次に選べます

## Mozc UT 辞書の語

utuhiro78 さんの Mozc UT 辞書のうち，配布物に入れられるライセンスの 6 つ(mozcdic-ut-sudachidict・mozcdic-ut-neologd・mozcdic-ut-personal-names・mozcdic-ut-place-names・mozcdic-ut-jawiki・mozcdic-ut-edict2)から語を足します．`sources/sources.txt` にリポジトリのコミットと SHA-256 を書いてあり，同じファイルから同じ辞書ができます．

UT 辞書は読みと表記だけで品詞を持たず，雑多な語も多いので，次のように足します．

- 品詞: 人名の辞書は「名詞,固有名詞,人名,一般」，地名の辞書は「名詞,固有名詞,地域,一般」，SudachiDict・NEologd・Wikipedia の見出しから作った辞書は「名詞,固有名詞,一般」，EDICT2 から作った辞書は「名詞,一般」にします．EDICT2 は動詞・形容詞・句も含むので，表記がひらがなで終わる語は足しません
- 除く語: 壊れた書き方の語(下の「壊れた書き方」)，読みが 4 文字より短いか 20 文字より長い語，表記が 20 文字より長い語，名前に使う記号(空白・=-&'.!?)以外の記号やほかの文字体系(ハングル・ギリシャ文字など)を含む語，記号と数字だけの語，表記のかなの部分が読みに現れない語(「四国ドック」を「シコクドックカブシキガイシャ」と読む組など)，英字だけの表記で，英字を 1 文字ずつ読んだ読みでも子音の並びが似た読みでもない語
- 値: 既存の語より控えめにします．品詞ごとに既存の語の値の下から 10% の位置を基準にし，元の辞書のコストと，複数の UT 辞書にあるかで少しだけ上げます．同じ読みの語が既にあれば，そのどれよりも下に置きます．既存の候補の並びは変わらず，UT 辞書の語はそのあとに入ります

GPL の UT 辞書(mozcdic-ut-skk-jisyo・mozcdic-ut-alt-cannadic)は使いません．UT 辞書を組み合わせる merge-ut-dictionaries が使う Wikipedia の見出し(CC BY-SA)によるコストの調整も使いません．

## NEologd と SudachiDict の元のデータの語

Mozc UT 辞書の NEologd・SudachiDict は名詞だけなので，元のデータからも語を足します(v0.4.0 から)．どちらも Apache License 2.0 です．

- [mecab-ipadic-NEologd](https://github.com/neologd/mecab-ipadic-neologd) の seed(固有名詞・一般名詞・形容詞・副詞)を `tools/add_neologd.py` で足します．品詞は IPAdic の番号なので，そのまま使います．形容詞を伸ばした書き方(「あかるうううういっ」)や顔文字など，表記のかなが読みに現れない語や記号を含む語は，Mozc UT 辞書と同じ決まり(`tools/wordfilter.py`)で除きます
- 表記の揺れの seed(ortho-variant の 3 つ)は v0.5.1 から足しません．文を解析するために，元の語(原形)の一部の漢字をかなやカタカナに機械的に置き換えた書き方(「具アン」→ 具案，「ハッ声」→ 発声，「あさ顔」→ 朝顔)で，変換の候補を乱すためです．形容詞と副詞も，表記が原形(形容詞は原形の活用形)の行だけを足し，伸ばした書き方(「あぶなーいッ」→ あぶない，「かりかりーっ」→ かりかりかりっ)は足しません
- [SudachiDict](https://github.com/WorksApplications/SudachiDict) の small・core・notcore の名詞を `tools/add_sudachi.py` で足します．品詞の体系が違うので，名詞の小分類を IPAdic の品詞に引き直します(動詞・形容詞は活用の型の対応が要るので足しません)
- 値: 両方の辞書にある同じ品詞の語で，元の辞書のコストと azooKey の値の対応を求め(Mozc の語と同じ)，まれな語が多いので 1 下げます．同じ読みの語が既にあれば，そのどれよりも下に置きます．既存の候補の並びは変わりません

## 壊れた書き方

v0.5.1 から，元のデータの語のうち，変換の候補や文節の区切りを乱す書き方を除きます(`tools/brokenwords.py`)．Mozc・Mozc UT 辞書・NEologd・SudachiDict から足す語に当てます．

- 促音で切った交ぜ書き: 同じ読みに漢字だけの語があり，その語の常用漢字を，促音で終わる読みのかなに置き換えた書き方(「はっせい」の はっ声・ハッ声，「あっせい」の アッ制，「けったい」の けっ滞)．漢語の頭の字を読みのかなにした形で，新聞や公用文の交ぜ書き(改ざん・破たん)と違って使われません．常用漢字は Unicode の Unihan データベースの印(kJoyoKanji)で見分けます．送りがなの促音(引っ越し・ぶっ飛ぶ)は，元の語の漢字の位置に当たらないので除きません
- 読みのかなだけの名詞: 表記が読みのひらがなかカタカナそのもので，同じ読みに，その語より値で 3 以上よく使われる漢字を含む語があるもの(「はっせい」の はっせい・ハッセイ，「りくぐん」の リクグン)．ひらがなとカタカナの候補は変換エンジンが作ります．カタカナで書くのが習わしの語(ギンザケ・イワツバメ)は漢字の語と値がほとんど変わらないので残ります．人名には当てません
- 読みが促音で始まる語(「っちゅねん!」)と，読みが促音で終わる数詞(「じゅういっ」の 十一)．語の途中で切った切れ端です

azooKey の辞書の語は，次の文節の切れ端だけを除きます．どれも前後の語とつながって，「はッ制」(は＋ッ＋制)や「はっ再の」のような候補を作っていました．数と助数詞をつなぐ数詞(八本 の「はっ」→ 八・8)と，接尾の語(っ子・っぽい・っぱなし)は残します．

- 読みが促音で始まる，カタカナだけの名詞(ッ・ック・ット)
- 読みが促音で終わる 2 文字の，カタカナだけの名詞(イッ・セッ・ガッ)．「イッ所に」「ガッ校に」のような候補を作っていました．同じ読みの感動詞と副詞(ハッとする の「ハッ」)は残ります
- 読みが促音で終わる，かなで書いた数詞(はっ・いっ・じっ)
- 送りがなを落とした 1 字の一般名詞(待 の まち，書 の かき，考 の かんがえ，驚 の おどろき など 119 語．v0.5.3 から)．同じ字の動詞の連用形と読みが同じで，送りがなを付けた名詞(待ち・書き)のほうが値で 2 以上よく使われるもの．Zenzai が 1 語の「まち」を「待」にしていました．「送り仮名の付け方」(1973)の通則 2 の例外で送りがなを付けない名詞(光・隣・氷・恋・組・帯・畳・頂・係 など)，濁った頭の読み(確認済 の ズミ)，接尾・助数詞の品詞の語は残します．SudachiDict から足し直さないよう，SudachiDict の語にも当てます
- 促音で切った交ぜ書きの名詞(てっ底・やっ介・ひっ算・まっ赤 など 36 語．v0.5.2 から)．同じ読みの漢字だけの名詞(徹底・厄介)が azooKey の辞書にあるもの．常用漢字になる前の表外字(鬱・勃・褐・叱・闊・抹)をかなにした新聞の交ぜ書き(うっ血・うっ屈・うっ積・うっ憤・うっ滞・ぼっ発・かっ色・しっ責・かっ歩・まっ消)は残します

交ぜ書きを広く(はん称・総らん のように促音で切っていないものまで)除く決まりも試しましたが，Mozc の語の見本 100 語のうち 3〜4 割が正しい書き方(一人ひとり・障がい者・色メガネ・ふだん着・数十ヵ所・地名の 湯ノ沢)でした．2010 年に常用漢字になった字の交ぜ書き(破たん・補てん)とも見分けられないので，促音で切ったものに絞っています．

## 助数詞の音の変わる読み

数のあとで音の変わる助数詞の読みのうち，azooKey の辞書の助数詞の品詞に無いものを足します(v0.5.3 から．`sources/counter-readings.tsv`)．匹 の ピキ・ビキ，敗 の パイ，服 の フク・プク，発 の パツ，筆 の ピツ，足 の ゾク，軒 の ゲン の 9 語です．意味の ID は元の読み(匹 の ヒキ)の助数詞の語と同じにします．値は，元の読みの値から，azooKey の辞書にある助数詞の音の変わる読み(杯 の ハイ と パイ・バイ など)の値の差の中央値を引きます(半濁音 1.84，濁音 0.74)．元の読みと同じ値にすると，同じ読みの別の助数詞より先に出ました(よんぱい が 四杯 でなく 四敗)．元の読みに助数詞の語が無いもの(服)は，元の読みでいちばんよく使う語の値を使います．「ろっぴき」が「6ぴき」になっていました．

## 促音を落とした読みの揺れ

azooKey と Mozc の辞書には，促音を落として打ったときのための読みの揺れ(決して の「けして」，支える の「つかえる」，湿気 の「しけ」)が入っています．揺れの読みが，同じ読みのふつうの語(けして の「消して」，しけ の「時化」)より先に出ないよう，`tools/demote_sokuon_variants.py` で値を下げます．

- 同じ表記に，読み R と，R に「ッ」を 1 つ足した読み R' があり，R' のほうがよく使われる(値が大きい)とき，R を揺れとみなして値を 5 下げます．語は消さないので，候補から選べ，Zenzai が文脈から選ぶこともできます(「けしてゆるさない」は「決して許さない」)
- 下げた語と同じ読み・同じ品詞で，表記が読みのかなそのものの語(決して に対する副詞の「けして」)も一緒に下げます
- R のほうがよく使われる組(欲し の「ほし」と「ほっし」)は変えません．かなの表記の語どうし(バタ と バッタ)は別の語のことが多いので，組にしません

## 専門用語の辞書

`Dictionary/terms.tsv` は，通常の辞書に無い専門用語を分野ごとに並べたものです(v0.5.0 から)．Hajime IME は，設定で選んだ分野の語だけを候補に足します．通常の辞書(LOUDS)とは別のファイルなので，分野を切っても通常の辞書の語は残ります．

- 1 行は「読み<TAB>語<TAB>品詞<TAB>分野<TAB>重なり」です．読みはひらがな，品詞は noun か properNoun，分野は `tools/term_fields.py` の id です．行全体の UTF-8 のバイト順に並べます(読みで二分探索するため)
- 重なりは，読みが通常の辞書の語とどう重なるかです．0 は重ならない，1 は同じ読みの語がある(「しかん」の 士官)，2 は通常の辞書の 2 つの語の読みに分けられる(「たたいた」は「たたい」と「た」)．Hajime IME は重なる語の点数を下げ，ふだんの語を押しのけたり，語の切れ目をまたいで入り込んだりしないようにします
- 分野は 24 個です(`tools/term_fields.py`)．JMdict の分野の印(96 種)をすべてどれかの分野に割り当て，Wikidata は分野ごとのクラス(病気・医薬品・化合物・定理・鉱物・建築要素・法的概念・プログラミング言語など)の項目と，2 段までの下位のクラスを使います
- JMdict(`sources/sources.txt` で jmdict-simplified の版を固定)からは，分野の印の付いた名詞の語義の語を入れます．古語・廃語の語義と，まれ・古い・探すときだけの表記は除きます．全角の英数字は半角にします
- Wikidata からは，日本語のラベルと名前の読み(P1814)を使います．ラベルがカタカナだけならラベルを読みにします．問い合わせの結果は `sources/wikidata-terms.tsv` にコミットし，辞書を作るときはこのファイルだけを使います(作り直しは `tools/fetch_wikidata_terms.py sources/wikidata-terms.tsv --raw work/wikidata-terms-raw.json`)
- 通常の辞書に同じ読みと語があるもの，同じ読みで書き方の似た語があるもの(「寄り切り」に対する「寄りきり」，「あいまい検索」に対する「曖昧検索」)，読みが 3 文字より短いもの，語がカタカナだけのもの(カタカナへの変換で候補に出る)は入れません．書き方の違いとカタカナだけの語は，点数を下げても Zenzai の選び方を変え，ふだんの書き方や語の切れ目を変えてしまったためです

## 評価

Hajime の `make evaluate DICTIONARY=<展開した Dictionary>` で測れます．v0.1.0 の結果(Zenzai なし，第 1 候補の正解率 / 上位 10 候補に正解が入った割合)は次のとおりです．

| 評価セット | azooKey の辞書 | この辞書 |
|---|---|---|
| 人名(Wikidata，300 語) | 18.7% / 35.7% | 27.3% / 45.3% |
| 地名(Wikidata，300 語) | 30.7% / 49.3% | 41.0% / 58.3% |

v0.5.3 では，助数詞の音の変わる読み 9 語を足し，送りがなを落とした 1 字の一般名詞 119 語を除きました．数と助数詞の読み 199 個(いっ・に・さん・よん・ろっ・なな・はっ・じゅっ・ひゃっ・なん と 20 の助数詞)の第 1 候補の正解は，Zenzai なしで 68 → 80，Zenzai ありで 69 → 70 になりました(ろっぴき → 6匹，よんぴつ → 四筆 など)．悪くなった読みはありません．「じゅっ」「ひゃっ」のあとの助数詞(じゅっぴき・ひゃっぷく)は，数とつながらず，Zenzai なしでは前もあとも正しくなりません．AJIMEE-Bench・Tatoeba・Hajime の conversion-basic と conversion-everyday・語彙 3 つの第 1 候補は，Zenzai あり・なしとも 1 件ずつ見て v0.5.2 と同じでした．除いた名詞の読みと，送りがなを付けない名詞(光・隣・氷・恋・組・煙 など 17 語)を変換すると，変わったのは Zenzai ありの「まち」(待 → 待ち)だけです．送りがなを省く複合語(税込・欠席届・確認済・書留・受付・割引 など 48 語)の第 1 候補は，Zenzai あり・なしとも v0.5.2 と同じでした．Hajime IME の操作の数(R-25)は，Zenzai ありで 1 文(「翌月の初め」)が減り，増えた文はありません．
